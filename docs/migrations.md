# 升级与格式迁移

升级以“先只读检查当前状态，再使用新预览执行明确变更”为原则，保留未知 / 损坏数据；没有后台全局迁移或自动跨文件回滚。

## 应用、bridge 与接入路径

先核对自身 `version`、包内 bridge 清单和 [支持版本](compatibility.md)。保持经过验证的应用包在稳定路径，退出旧实例后更新；原生包安装、签名及实际操作尚待 27.3 验收。本轮不需要用户升级 beta 或启用配置。

相同路径升级也需要使用新包的 helper 重新预览 `integration install`；总指纹包含两份配置与 bundle 版本 / helper 摘要。移动后使用新的 `--app` 路径重新预览并应用，只更新自身 hooks / notify wrapper，不改其他工具的处理器或原 notify argv。命令与备份步骤统一见 [安装、升级与卸载](installation.md)。

曾用独立 `hooks install` 接入的配置可以再由统一 `integration install` 预览：已有完整标记会识别为自身条目，notify 单独显示是否需要变化。工具不搜索其他目录、内联配置或项目级配置，不为未知标记猜测归属。旧 helper 文件是否删除由用户在确认配置已修复后决定，不由安装器批量清理。

## 事件与位置

- v1 事件继续读取，source / kind / turn 不存在时保持未知，不原地改写历史。
- 新 bridge 写 v2；旧 v1 读取器不能读取 v2，不能把“新版本兼容旧数据”当成双向兼容。
- 可选位置独立为 schema v1。没有位置或只有旧 block 的记录继续展示，不补造 tab / workspace / window 或认证，不据此执行精确定位。
- 损坏、未知版本、超大、ID 不匹配和不安全文件保留并计数；完整扫描超预算时不给部分确认。诊断离线清单只统计文件，不能说明当前会话，详见 [诊断](diagnostics.md)。

事件兼容不表示 Codex 外部契约自动兼容。升级 Codex 后须重新核对六类 hooks、notify 字段与信任 / 重载，完成、许可等待及工具错误的含义见 [事件契约](codex-events.md)。

## 会话 checkpoint 与清除边界

checkpoint v1 可读，且不允许混入后来才有的位置数据；v2 支持位置与同一轮次 / UUID / 工具窗口。只读 load 不迁移或写回，下一次必要保存使用当前 v2；保存受原 revision、目录身份和 inbox scope 检查约束。

重启会重新扫描源文件，沿用原观察时间和清除导入边界，不因读取时刻刷新状态。清除后保存的空 store 与已存在文件摘要在同一 checkpoint 中，旧事件不立即重新变成会话；不能删除 checkpoint 来模拟“安全清除”，这会丢掉导入边界。

未知版本、损坏、超限或 scope 不匹配时保留原文件并报告不可用，暂停需要确认的实时行为。先按来源健康、保存问题码和备份核对；需要放弃状态时，通过既有 `state clear` 或应用管理菜单**先预览，再明确清除**，不手工批量删除状态目录。独立 CLI 清除要求空闲接收者 lease；原始事件和独立应用显示 / 提醒设置保留。说明见 [会话持久化](session-persistence.md)。

## 应用偏好

UserDefaults 的 v1 显示 / 提醒文档与 checkpoint 中已读、忽略、置顶、选择分别保存。偏好损坏 / 未来版本时保留原键，默认关闭提醒、隐藏项目名并用 1 小时界面历史降级，普通编辑被阻止；只有「恢复显示与提醒默认值」才解除阻止。

恢复默认值不清除事件或会话 checkpoint，也不自动注销系统登录项。登录项实际状态由系统查询，通知权限仍需用户明确启用动作；未知格式没有无损降级保证，见 [偏好设置](preferences.md)。

## Codex 配置与回退

预览不创建配置 / 锁 / 备份；只有 `--apply --expect ... --backup-dir ...` 才写入。hooks 保留外部字段，JSON 排版可能重排，原始字节备份可供核对。notify 只编辑顶层数组的字节范围，支持单行字符串元素及数组跨行 / 注释；重复、dotted / table notify、不支持的值或不完整输入会拒绝，不重写整份 TOML。

安装先 hooks 后 notify，卸载反向；没有跨文件事务。部分失败只确认已完成步骤并保留备份。解除原因后重新预览当前状态，不复用旧指纹、不直接把旧备份覆盖后来编辑。

完整文件回退须比较 receipt、原存在状态、权限与当前变更；回执和 raw before 含真实配置，保存在用户指定的私有备份目录，不能当诊断附件分享。当前没有自动 restore 命令。若仅退出 TideIsland 接入，优先重新预览 `integration uninstall`，它恢复原 notify 并移除自身 hooks；数据默认保留。详见 [安装与恢复](installation.md)。

## 降级限制

尚无已发布旧版的双向迁移承诺。降级前保留配置备份并核对旧读取器支持的事件 / checkpoint / 偏好格式；不把 v2 文件改数字成 v1，不清空未知字段来强行通过检查。包版本、事件协议、显示设置和系统活动分别处理，真实跨版本演练由 [统一验收](development-progress.md#6-macos-273-正式环境统一验收)记录。
